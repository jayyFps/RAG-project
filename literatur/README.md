# Folder `literatur/`

Tempat menyimpan **artikel jurnal/konferensi** rujukan skripsi beserta catatan ringkasannya.
Semua isi di sini **boleh masuk Git** (bukan data sensitif), asalkan lisensi artikel mengizinkan.

## Aturan penamaan berkas

```
<Tahun>_<PenulisUtama>_<KataKunci>_<VenueSingkat>.pdf
<Tahun>_<PenulisUtama>_<KataKunci>_<VenueSingkat>.md   # catatan ringkasan
```

Contoh:

```
2023_Nogueira_EvaluatingRAG_arXiv.pdf
2023_Nogueira_EvaluatingRAG_arXiv.md
2024_Lewis_HybridRetrieval_EMNLP.pdf
```

## Isi catatan ringkasan (`.md`) minimal

- **Sitasi lengkap** + DOI/URL (yang sudah diverifikasi bisa dibuka).
- **Status akreditasi** jurnal: Scopus (Q1–Q4) atau SINTA (1–6) — cek ulang di
  <https://sinta.kemdikbud.go.id> dan <https://www.scopus.com>.
- **Masalah**, **metode**, **dataset**, **metrik**, **hasil**, dan **celah (gap)** yang
  disorot penulis.
- **Hubungan dengan skripsi ini**: dipakai di bagian mana (Langkah 3/4/5/6, tabel
  penelitian terdahulu).

## Kaitan dengan `README.md`

Setiap artikel yang dipakai **wajib** muncul di
[Langkah 6 — Studi Literatur](../README.md#langkah-6--studi-literatur-dan-tabel-penelitian-terdahulu-state-of-the-art)
(Tabel penelitian terdahulu) dan di [Daftar Referensi](../README.md#daftar-referensi).
Berkas PDF/ringkasan di sini adalah **bukti** bahwa artikel benar-benar dibaca, bukan
disalin dari keluaran AI.

> **Integritas:** status setiap rujukan adalah *terduga* sampai berkas aslinya Anda buka
> dan baca. Jangan menyalin sitasi tanpa verifikasi.
